# /headline

명령일 당일 발행된 매크로 관련 뉴스 헤드라인을 주제별로 수집해 Notion 헤드라인 DB에 저장합니다.

## 사용법
- `/headline` — 오늘 날짜 기준 데일리 헤드라인 수집 및 업로드

---

## 실행 순서
1. 오늘 날짜 확인 (제목에 `YY/MM/DD` 형식 사용)
2. 매크로 주제 5~6개 선정 — 당일 뉴스 흐름 기준으로 임팩트 있는 꼭지 우선 선택
   - 선정 풀: 금리·중앙은행, 환율, 유가·에너지, 미중무역·지정학, 글로벌 경기·기업, 채권·금융시장
3. 각 주제별 WebSearch — **반드시 Agent(서브에이전트)를 주제 수만큼 동시에 spawn해 병렬 실행** (순차 실행 금지)
   - 각 서브에이전트는 독립적으로 WebSearch 1회 실행 후 결과 반환
   - 모든 에이전트 결과가 수집된 뒤 통합·중복 제거 작업을 진행한다
4. 전체 25개 안팎의 헤드라인을 주제별로 적절히 분배
   - 동일 사건을 다룬 중복 기사 제거 (같은 사건이면 가장 상세한 기사 1개만 유지)
   - URL 확인 필수 — 링크가 없거나 페이지 홈으로만 연결되는 기사 제외
   - **트레이딩·차트 기사 배제**: 기술적 분석, 단기 매매 아이디어, 차트 패턴만 다루는 기사 제외 (예: Orbex, DailyForex 스타일)
   - 매크로 인사이트(정책, 데이터, 시장 구조 변화)가 있는 기사만 선택
5. 아래 레이아웃에 맞게 본문 작성
6. Notion MCP(`notion-create-pages`)로 헤드라인 DB에 업로드
7. **업로드 후 검증 (필수)**: `notion-fetch`로 페이지를 가져와 URL 링크·한국어 텍스트 깨짐 확인
8. **깨진 글자 발견 시**: `notion-update-page`로 수정 후 재검증

---

## 검색 전략

**핵심 원칙: 명령 당일 발행 기사만 사용**
- 발행일이 명령일과 다른 기사는 사용하지 않는다
- URL에서 날짜를 확인할 수 없으면 검색 스니펫의 날짜를 참조한다
- 당일 기사가 부족하면 쿼리를 바꿔 재검색한다

**쿼리 구성 규칙**
- 반드시 오늘 날짜(예: `May 8 2026`)를 쿼리에 포함
- 영문 쿼리 우선 (Reuters, Bloomberg, CNBC, FT, WSJ)
- 한국어 꼭지는 영문 검색으로 충분하지 않을 때 추가 실행
- 각 기사마다 한국어 번역 제목을 작성한다 (영문 원문은 `//` 구분자 뒤에 보조로 포함)

**헤드라인 선별 기준**
- 시장 임팩트가 큰 기사 우선
- 동일 사건 중복 제거
- 의견·칼럼·전망 기사보다 팩트 기반 속보 우선
- **트레이딩·차트 기사 배제**: 기술적 분석, 단기 매매 아이디어, 차트 패턴만 다루는 기사 제외

## 레이아웃

```
[본문 시작 — 인트로 문단 없이 바로 섹션 시작]

## 주제명 (예: 금리 · 중앙은행)

- [한국어 번역 제목](기사 URL) // 영문 원문 헤드라인 // 출처
- [한국어 번역 제목](기사 URL) // 영문 원문 헤드라인 // 출처

---
## 주제명 (예: 환율)

- [한국어 번역 제목](기사 URL) // 영문 원문 헤드라인 // 출처
```

**포맷 규칙**
- 각 bullet은 `[한국어번역](URL) // 영문원문 // 출처` 형식 (공백 포함 `//` 구분자 필수, 시간 없음)
- 한국어 번역은 뉴스 의미를 담은 자연스러운 번역 (원문 음역 금지)
- 전체 25개 안팎, 주제별 적절 분배 (임팩트 큰 꼭지에 더 많이 배정)
- 구분선(`---`)으로 주제 블록 시각적으로 분리
- 인트로 문단 없이 바로 `## 섹션`으로 시작
