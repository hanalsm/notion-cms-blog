# /headline

명령일 당일 발행된 매크로 관련 뉴스 헤드라인을 주제별로 수집해 Notion 헤드라인 DB에 저장합니다.

## 사용법
- `/headline` — 오늘 날짜 기준 데일리 헤드라인 수집 및 업로드

---

## 실행 순서
1. 오늘 날짜 확인 (제목에 `YYYY/MM/DD` 형식 사용)
2. 매크로 주제 5~6개 선정 — 당일 뉴스 흐름 기준으로 임팩트 있는 꼭지 우선 선택
   - 선정 풀: 금리·중앙은행, 환율, 유가·에너지, 미중무역·지정학, 글로벌 경기·기업, 채권·금융시장
3. WebSearch 병렬 실행 — **반드시 Agent(서브에이전트)를 동시에 spawn해 병렬 실행** (순차 실행 금지)
   - **에이전트 구성 — A·B 2개 고정 실행 (C·D 추가 금지)**
     - 에이전트 A (필수): **외신 주요** — Reuters, Bloomberg, CNBC, FT, WSJ 대상 영문 검색 (`May DD YYYY` 날짜 포함)
     - 에이전트 B (필수): **한국 주요** — 한국경제, 매일경제, 연합인포맥스 대상 한국어 검색 (`YYYY년 M월 D일` 날짜 포함)
     - 에이전트 C·D: **절대 spawn 금지** — 결과가 부족해도 A·B 결과만으로 작성한다
   - 모든 에이전트 결과가 수집된 뒤 통합·중복 제거 작업을 진행한다
4. **날짜 검증 게이트 (필수)** — 수집된 기사 전체를 날짜 기준으로 필터링
   - 각 기사의 발행일을 URL 패턴(`YYYY/MM/DD`) → 스니펫 날짜 → 기사 본문 날짜 순으로 확인
   - **명령일과 다른 날짜의 기사는 무조건 제외** (전날·전주·작년 기사 모두 포함 금지)
   - 날짜를 확인할 수 없는 기사도 제외
   - 섹션별 당일 기사가 3개 미만이면 해당 섹션 쿼리를 바꿔 **반드시 재검색**
   - 재검색 후에도 당일 기사가 없으면 해당 섹션 자체를 제외 (억지로 채우지 않는다)
5. 전체 20개 안팎의 헤드라인을 주제별로 적절히 분배
   - 동일 사건을 다룬 중복 기사 제거 (같은 사건이면 가장 상세한 기사 1개만 유지)
   - **URL 접근성 검증 필수**: 헤드라인으로 선정한 기사의 URL을 `WebFetch`로 직접 접근해 확인한다
     - 정상 기사 본문이 로드되면 사용 가능
     - 404·403·홈으로 리다이렉트·페이월 차단 등은 해당 기사 즉시 제외하고 대체 기사 선정
     - WebFetch 실패(접근 불가) 기사는 절대 포함하지 않는다
   - **트레이딩·차트 기사 배제**: 기술적 분석, 단기 매매 아이디어, 차트 패턴만 다루는 기사 제외 (예: Orbex, DailyForex 스타일)
   - 매크로 인사이트(정책, 데이터, 시장 구조 변화)가 있는 기사만 선택
6. 아래 레이아웃에 맞게 본문 작성
7. Notion MCP(`notion-create-pages`)로 헤드라인 DB에 업로드
8. **업로드 후 검증 (필수)**: `notion-fetch`로 페이지를 가져와 URL 링크·한국어 텍스트 깨짐 확인
9. **깨진 글자 발견 시**: `notion-update-page`로 수정 후 재검증

## 검색 전략

**핵심 원칙: 명령 당일 발행 기사만 사용**
- **발행일이 명령일과 하루라도 다른 기사는 절대 사용하지 않는다**
- URL에서 날짜를 확인할 수 없으면 검색 스니펫의 날짜를 참조한다
- 날짜 확인이 불가능한 기사는 제외한다
- 당일 기사가 부족하면 쿼리를 바꿔 재검색한다 (재검색 없이 오래된 기사로 채우는 행위 금지)

**출처 우선순위 (검색 · 선별 · 할당 모두 이 순서 적용)**

| 순위 | 구분 | 대상 |
|------|------|------|
| 1 | 외신 주요 | Reuters, Bloomberg, CNBC, FT, WSJ |
| 2 | 한국 주요 | 한국경제, 매일경제, 연합인포맥스 |
| 3 | 외신 기타 | AP, AFP, Nikkei, SCMP 등 |
| 4 | 한국 기타 | 한겨레경제, 서울경제, 아시아경제 등 |

**쿼리 구성 규칙**
- 반드시 오늘 날짜(예: `May 11 2026`)를 쿼리에 포함
- 에이전트 A·B만 실행한다 (C·D는 어떤 경우에도 추가 금지)
- 전체 헤드라인 중 **한국 언론사(2순위) 기사를 최소 4개 이상** 포함한다
  - 한국 기사가 부족하면 에이전트 D를 추가하는 대신, 에이전트 B의 쿼리를 바꿔 재검색한다
- 각 기사마다 한국어 번역 제목을 작성한다 (영문 원문은 `//` 구분자 뒤에 보조로 포함)

**헤드라인 선별 기준**
- **출처 우선순위 순으로 선별**: 외신 주요 → 한국 주요 → 외신 기타 → 한국 기타
- 시장 임팩트가 큰 기사 우선
- 동일 사건 중복 제거
- 의견·칼럼·전망 기사보다 팩트 기반 속보 우선
- **트레이딩·차트 기사 배제**: 기술적 분석, 단기 매매 아이디어, 차트 패턴만 다루는 기사 제외

**포맷 규칙**
- 첫 줄: `[한국어번역](URL) // 영문원문 // 출처` (공백 포함 `//` 구분자, 시간 없음)
- 둘째 줄: 헤드라인 아래 2칸 들여쓰기로 한국어 요약 1~2문장 (bullet 항목의 들여쓰기 continuation)
- 요약은 수치·정책 결정 등 팩트 중심, 한국어로 작성
- 한국어 번역은 뉴스 의미를 담은 자연스러운 번역 (원문 음역 금지)
- 전체 20개 안팎, 주제별 적절 분배 (임팩트 큰 꼭지에 더 많이 배정)
- 구분선(`---`)으로 주제 블록 시각적으로 분리
- 인트로 문단 없이 바로 `## 섹션`으로 시작
