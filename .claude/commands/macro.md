# /macro

매크로 분석 글을 작성해 Notion 블로그 DB에 업로드합니다.

## 사용법
- `/macro` — 오늘 날짜 기준 가장 임팩트 있는 이슈를 AI가 선정해 작성
- `/macro 환율` — 지정 키워드 중심 심층 분석 글 작성

$ARGUMENTS 가 비어 있으면 모드 1(자유 주제), 값이 있으면 모드 2(키워드: $ARGUMENTS) 로 실행한다.

---

## 모드 1 — 자유 주제

**주제 선정 기준**: 금리, 중앙은행, 환율, 유가, 미중 무역, 글로벌 경기 중 당일 시장에서 가장 임팩트 있는 이슈 1개 선택.

## 모드 2 — 키워드 지정

키워드(`$ARGUMENTS`)를 중심으로 WebSearch를 2회 이상 실행해 충분한 데이터를 수집한 후 작성한다.

---

## 공통 실행 순서
1. 모드 판단: `$ARGUMENTS` 유무로 자유 주제 vs 키워드 지정 구분
2. WebSearch로 최신 뉴스 검색 (아래 검색 전략 적용, 3회 이상)
3. 검색 결과를 바탕으로 한국어 블로그 글 초안 작성
4. **오타 검수**: 아래 체크리스트를 항목별로 직접 소리 내어 확인하듯 검토
5. 검수 후 수정사항 반영한 최종본으로 Notion MCP(`notion-create-pages`) 업로드
6. **업로드 후 검증 (필수)**: `notion-fetch`로 방금 생성한 페이지를 다시 가져와 실제 저장된 텍스트를 확인
   - MCP JSON 레이어에서 한국어가 조용히 깨질 수 있다 (예: `잇따라`→`잃따라`, `촉발할`→`쳙발할`, `통화정책`→`통화정솵`)
   - 업로드 전 검수를 통과해도 저장 후 다를 수 있으므로 fetch 검증은 생략할 수 없다
7. **깨진 글자 발견 시**: `notion-update-page`로 해당 속성 또는 `update_content`로 본문 수정, 재검증

---

## 검색 전략

**핵심 원칙: 명령 당일 기준 최대 1~2일 이내 기사만 사용**
- 검색 결과를 받은 후 반드시 각 기사의 **발행일을 확인**한다
- 발행일이 명령일 기준 **2일을 초과한 기사는 내용으로 사용하지 않는다**
- 발행일을 확인할 수 없는 기사도 사용하지 않는다
- 최신 기사가 충분하지 않으면 검색 쿼리를 바꿔 재검색한다

**쿼리 구성 규칙**
- 반드시 현재 연·월·일(예: `May 8 2026`)을 쿼리에 포함
- 한국어 쿼리에는 절대 예측성 키워드(예: `전망`, `예상`, `시나리오`)를 단독으로 쓰지 않는다
- 3회 검색 구성:
  - 1회: 영문 + 날짜 명시 + 신뢰 소스 (Reuters, Bloomberg, CNBC, EIA, IEA, Fed)
  - 1회: 한국어 + `YYYY년 M월 D일` 명시 (국내 금융 미디어: 한국경제, 매일경제, 연합인포맥스)
  - 1회: 공식 기관 데이터 중심 쿼리 (EIA, IEA, Fed, BOK 공식 발표)

**기사 날짜 검증 절차**
1. 각 링크의 URL 또는 본문에서 날짜 추출
2. 명령일 기준 2일 초과 기사는 제외 표시
3. 사용 가능한 기사가 2개 미만이면 쿼리를 수정해 재검색
4. 최종적으로 사용한 기사의 날짜를 글 작성 전 명시적으로 확인

## 오타 검수 체크리스트

**1단계 — 인코딩·깨진 문자 (최우선)**
- [ ] 이모지가 문장 중간에 삽입되지 않았는가
- [ ] 한글 글자가 이상하게 바뀌지 않았는가
- [ ] 깨진 문자(□, ?, )가 없는가
- [ ] 이중 공백이 없는가

**2단계 — 맞춤법·어휘**
- [ ] 동사 어미가 자연스러운가
- [ ] 조사가 올바른가 (이/가, 을/를, 은/는)
- [ ] 띄어쓰기 오류가 없는가
- [ ] 문장이 중간에 끊기지 않고 완결되는가

**3단계 — 숫자·단위·고유명사**
- [ ] 숫자 단위가 일관적인가 (달러, 배럴, %, bp)
- [ ] 고유명사 표기가 통일됐는가 (Fed / FOMC / OPEC / WTI / Brent / IEA / EIA)
- [ ] 불필요한 영문 혼용이 없는가

**4단계 — 요약(속성) 별도 검수**
- [ ] 요약 문장도 본문과 동일 기준으로 검수
- [ ] 요약이 2~3문장 이내인가
